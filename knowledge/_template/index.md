# Domain Index Template

This page navigates the topic templates. For a new domain, create a short index
with `## Navigation Hints` and a `Task | Target` table linking actual domain pages,
or the explicit empty state `No navigation hints yet.`. Replace category examples
with that domain's real navigation; do not copy this template hub's links unchanged.

## Internal knowledge

- `self/<topic>.md` — internal discovery, decision, constraint, or procedure.

## Derived knowledge

- `derived/<topic>.md` — source-backed summary with provenance.

## Sources

- `sources/<file>` — unchanged source material, when retained.
